# Changelog

## 1.0

- Initial public release.
- Complete Battery and Performance profile switching for Horizon OC.
- Full Horizon OC `config.ini` and `hoc.kip` save/restore.
- Automatic outgoing-mode save before switching.
- Full ReverseNX-RT folder saved/restored with each mode when installed.
- Manual `Save Settings -> as Battery Mode / as Performance Mode` checkpoints also save ReverseNX-RT.
- Per-title Horizon clock profiles included automatically.
- Battery app-profile reset to stock/default clocks.
- Manual Safety Backup and Restore, including ReverseNX-RT snapshots for active/Battery/Performance states.
- Exact-state protection prevents automatic profile overwrite when state is unknown or unset.
- Structured Ultrahand menu with Change Profile, Save Settings, Initial Setup and Backup Files sections.
- Public documentation includes the dual-profile efficiency rationale and measured Red Dead Redemption battery-life example.
