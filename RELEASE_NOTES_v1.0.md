# Performance Modes v1.0

Initial public release.

## Install
Extract `Performance-Modes-v1.0.zip` to the root of the SD card.

## Highlights
- Battery / Performance mode switching for Horizon OC
- Full Horizon OC config and HOC KIP profiles
- Automatic outgoing-profile save
- Optional ReverseNX-RT per-title integration
- Battery app-profile reset
- Safety Backup / Restore
- Unknown-state overwrite protection

## Why two profiles?
A Performance profile can retain the voltage and memory headroom required for high clocks, while a Battery profile can be tuned only for the lower/stock clocks actually used there. On the development console, Red Dead Redemption at identical stock game clocks improved from 5 h 32 min to 6 h 05 min (+33 min / ~9.9% runtime) with the tuned Battery profile. Results vary by hardware and settings.
